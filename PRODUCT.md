# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Software engineers, engineering peers, technical recruiters, audio/music enthusiasts, and visitors seeking practical tech articles (cloud infrastructure, .NET, audio engineering in DAWs, and AI tooling) and Rasmus Højte's creative work.

## Product Purpose

Serve as the central home for Rasmus Højte (HOJTE.NET): an authoritative, fast-loading, and polished personal engineering and creative hub featuring technical articles, music/video projects, and professional links.

## Positioning

An authentic personal technical hub bridging software engineering (cloud, backend, architecture) and creative audio engineering/music production, distinct from boilerplate corporate blogs or generic developer link-trees.

## Operating Context

Desktop and mobile browsers. Readers consume in-depth technical walkthroughs with code snippets, diagrams, and media embeds, or navigate directly to external professional profiles (GitHub, LinkedIn).

## Capabilities and Constraints

- Gatsby 4 static site generation with React 18 and MarkdownRemark.
- Hosted on GitHub Pages at hojte.net.
- Modern CSS architecture (`src/style.css`) without heavyweight CSS frameworks.
- Fast hot-reload local development at `http://localhost:8000`.
- Preserve existing content, routes (`/`, `/devlog/`, `/content/blog/<slug>/`), and SEO metadata.

## Brand Commitments

- Name: HOJTE.NET / Rasmus Højte
- Tone: Crisp, technically sharp, authentic, understated confidence.
- Visual character: Elegant, purposeful dark mode, refined typography, and subtle micro-interactions without AI-generated UI clichés (no side-tab accent lines, gratuitous gradients, or cookie-cutter cards).

## Evidence on Hand

- Published technical articles in `content/blog/` covering Azure Key Vault, Reaper DAW/VST scaling, IdentityServer4, .NET Core, Decorator APIs, and AI in review.
- Active profiles on LinkedIn (https://www.linkedin.com/in/rasmus-valbro-h%C3%B8jte-4a2326110/) and GitHub (FrankDrebin893).

## Product Principles

1. **Content and craft first**: Code readability, typography hierarchy, and article structure take precedence over decorative noise.
2. **Distinctive identity**: Elevated personal aesthetic that feels bespoke and engineered, avoiding generic templates or AI-slop design tropes.
3. **Speed and responsiveness**: Lightweight, zero-layout-shift experience across mobile, tablet, and widescreen viewports.
4. **Intuitive orientation**: Seamless navigation between the personal landing hub, post list, and detailed articles.

## Accessibility & Inclusion

- WCAG AA contrast compliance across all text, links, and code blocks in dark mode.
- Explicit focus states, semantic HTML landmarks, and legible typography scale.
